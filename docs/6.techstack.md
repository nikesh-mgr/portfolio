# Tech Stack

## 1. Frontend

| Technology          | Purpose                         |
| ------------------- | ------------------------------- |
| **React.js**        | Build the user interface        |
| **Vite**            | Fast development and build tool |
| **React Router**    | Page and project routing        |
| **Tailwind CSS**    | Responsive UI styling           |
| **Framer Motion**   | Smooth animations               |
| **Lucide React**    | Icons                           |
| **Axios**           | API communication               |
| **React Hook Form** | Form handling                   |
| **Zod**             | Form/data validation            |

---

## 2. Backend

| Technology     | Purpose                     |
| -------------- | --------------------------- |
| **Node.js**    | Backend runtime             |
| **Express.js** | REST API development        |
| **Mongoose**   | MongoDB database management |

---

## 3. Database

### MongoDB

Used for dynamic data such as:

- Projects
- Blog posts
- Contact messages
- Experience
- Certifications

**MongoDB Atlas** will be used for cloud database hosting.

---

## 4. Security

| Package                | Purpose                      |
| ---------------------- | ---------------------------- |
| **Helmet**             | Secure HTTP headers          |
| **CORS**               | Control API access           |
| **express-rate-limit** | Prevent API abuse/spam       |
| **bcrypt**             | Password hashing             |
| **JWT**                | Admin authentication         |
| **HttpOnly Cookies**   | Secure token storage         |
| **Zod**                | Server-side input validation |

Security is mainly required for the optional **admin dashboard and contact API**.

---

## 5. File & Image Storage

| Technology     | Purpose                   |
| -------------- | ------------------------- |
| **Multer**     | Handle file uploads       |
| **Cloudinary** | Store and optimize images |

Used for:

- Profile image
- Project screenshots
- Certificates

---

## 6. Email

### Nodemailer / Email API

Used to send messages submitted through the contact form.

```text
Visitor
  ↓
Contact Form
  ↓
Express API
  ↓
Email Service
  ↓
My Email
```
