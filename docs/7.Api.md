# Portfolio Backend API Documentation

## 1. API Overview

This backend provides REST APIs for a personal developer portfolio.

### Base URL

```text
http://localhost:5000/api
```

> In production, replace the base URL with the deployed backend URL.

### Authentication

Admin-protected endpoints use:

```text
authMiddleware
```

The authenticated admin must provide the authentication credentials expected by the backend authentication middleware.

### Common HTTP Methods

| Method   | Purpose                         |
| -------- | ------------------------------- |
| `GET`    | Retrieve data                   |
| `POST`   | Create data / perform an action |
| `PATCH`  | Partially update data           |
| `DELETE` | Delete data                     |

# 4. Authentication APIs

Base route:

```text
/api/auth
```

---

## POST `/api/auth/create-admin`

### Description

Creates the initial admin account.

### Authentication

Public according to the route definition.

### Validation

Uses:

```text
createAdminSchema
```

### Request Body

The exact fields are determined by `createAdminSchema`.

Example structure:

```json
{
  "fullname": "Admin User",
  "email": "admin@example.com",
  "password": "your-password"
}
```

> Use the actual validator schema as the source of truth for required fields.

### Content-Type

```text
application/json
```

---

## POST `/api/auth/login`

### Description

Authenticates the admin and creates an authenticated session/token.

### Authentication

Public.

### Validation

Uses:

```text
loginSchema
```

### Request Body

The exact fields are determined by `loginSchema`.

Example:

```json
{
  "email": "admin@example.com",
  "password": "your-password"
}
```

### Content-Type

```text
application/json
```

---

# 17. Global Middleware

The application applies the following middleware globally.

```text
helmet()
cors()
```

### Rate Limiting

```text
rateLimiter
```

### Request Parsing

```text
express.json({
  limit: "1mb"
})

express.urlencoded({
  extended: true,
  limit: "1mb"
})
```

### Cookies

```text
cookieParser()
```

### Error Handling

Unknown routes are handled by:

```text
notFoundMiddleware
```

Global application errors are handled by:

```text
errorMiddleware
```

# 18. Frontend API Module Structure

The frontend can organize API calls according to these backend resources:

```text
src/
└── services/
    ├── authApi.js
    ├── projectApi.js
    ├── blogApi.js
    ├── certificateApi.js
    ├── contactApi.js
    ├── educationApi.js
    ├── experienceApi.js
    ├── skillApi.js
    ├── siteSettingsApi.js
    ├── resumeApi.js
    └── uploadApi.js
```

This keeps frontend API communication separated by feature and makes the UI components easier to maintain.
